# Pocket Gamer — Usher Positions (Abdali Boulevard)

Saturday usher plan for the Pocket Gamer event at Abdali Boulevard: an interactive map of every usher, runner and team-leader post, with the section lists underneath.

**Open `index.html` in any browser** — it is a single self-contained file (map image included), no install or build needed.

## What you can do
- **Search** (press `/`): find an usher by name, position or section; `Enter` jumps to the next match.
- **Focus** on Section A, B or C, **zoom** the map, and toggle **names** on the map.
- **Hover** a dot to see the usher's number, section, position and name.
- **Copy** the full roster as text.

## Legend
- Dots: green square = team leader · yellow = usher · blue = runner (فرار)
- Name colours: green = University of Jordan · orange = HTU · white = no university info
